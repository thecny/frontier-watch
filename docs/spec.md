# 芯片前沿雷达：首版规格

## 目标

每天汇总最近出现的 DSP、FPGA、可重构计算、嵌入式和相关硬件信息，按相关性排序，向用户手机发送一条含原文链接的简报。可在 GitHub Actions 或本地 Python 中运行。

## 输入

- arXiv 官方 RSS：信号处理、计算机架构和电子工程相关论文。
- GitHub Search API：近期创建的 FPGA、DSP、嵌入式开源项目。
- 经核实的硬件新闻 RSS。
- 本地可调的关键词、时间窗口、每期条数。

所有来源使用公开页面或公开 API，不抓取文章全文。来源失败时记录错误；至少一个来源成功才允许发送。单次运行不得向 arXiv 发出高频请求。

## 输出与筛选

- 仅保留时间窗口内的条目；根据领域关键词给出主题和分数，去除无关内容。
- 按稳定 ID 去重，已成功发送的条目不重复发送。发送失败不得标记为已发送。
- 手机简报包括日期、标题、来源、主题、简短介绍及直达链接；不需要付费 AI 服务。
- 无新条目时安静退出。`--dry-run` 打印简报，但不推送也不改变状态。

## 推送与运行

- 通过环境变量配置一种推送渠道，默认使用 Server酱 Turbo 送达个人微信，并提供 Bark（iPhone）、Telegram 和企业微信备选。
- 凭据不得写入配置文件、状态文件、日志或仓库。缺少必要凭据时以可理解的错误退出。
- 没有 GitHub 仓库时，Windows 安装脚本用当前用户的 DPAPI 保存 SendKey，并创建每天 09:17 的计划任务。
- GitHub Actions 也可每天北京时间上午运行，使用 GitHub Secrets 保存凭据，提交小型去重状态文件以跨运行持久化。

## 验收

1. 用离线测试验证 XML/JSON 解析、时间和关键词筛选、去重、状态更新时机、推送请求格式。
2. 能在无凭据环境用离线样例演示完整简报，并通过 `--dry-run` 实际抓取公开源。
3. README 用中文给出 Windows 本机和 GitHub Actions 两条配置路径与其他渠道配置。
